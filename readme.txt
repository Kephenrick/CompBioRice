This repository only contains the main files without the virtual environment, it is advised to first initiate a virtual environment. Please make sure to not interfere with the files if you wish to use it for its intended creation. However, it can be modified based on need.
Virtual environment initiation steps:
1. Open terminal in the folder you keep everything in
2. Make a virtual environment with any name using the command:
   python -m venv [environment name]
3. Activate the virtual environment using the command:
   [environment name]\Scripts\activate
4. Using the file 'requirement.txt', install the dependancies needed using:
   pip install -r requirements.txt
5. You can then run the app by using the command:
   streamlit run main.py
